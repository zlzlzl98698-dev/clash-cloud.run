### 2.1 一翻云 传输链路特征分析
- **过境通道类型（全节点 IEPL 物理专线 + 原生住宅 IP）**：采用内网以太网专线（IEPL）过境，数据在国内多线 BGP 入口封装后直接通过运营商物理内网传输至境外落地，不经过公网国际出口，因此在晚高峰（20:00–23:30）具备极强的抗拥塞与低抖动能力。
- **协议栈解析（`Hysteria 2 / VLESS-Reality / Shadowsocks`）**：包含基于 QUIC/UDP 暴力拥塞控制的 `Hysteria 2` 协议，在弱网或高丢包环境下仍能跑满高带宽。
- **全球节点分布（共 5 个地区）**：覆盖 **香港、台湾、日本、新加坡、美国**（覆盖港/台/日/新/美五地原生住宅 IP），标称峰值带宽为 **官方宣称单节点 2Gbps 大带宽、晚高峰 0 丢包**。
